# 驾驶模块候选

用户确认：同一驾驶页同时展示最多三个独立目的地，每个目的地最多三条真实备选路线；不是车载导航。不单独制作测试页。使用原 NAS 容器、管理授权和统一设置。

## 配置与限制

- 私有环境变量 KHD_AMAP_KEY（高德 Web 服务 Key）；不得把真实值、搜索词、坐标或真实路线提交到 GitHub。
- 默认关闭。启用前在高德控制台确认个人用途、有效权限及实际免费额度，核实地图许可允许家庭看板内短暂展示原图，再在设置确认位置传输、地图许可。不得购买或启用付费能力。高德 POI 2.0 官方文档标注企业试用；搜索可能不适用于个人账号，保留手输高德 GCJ-02 坐标。
- 最多三组，各自显示名称、起终点、独立开关和多个星期/时段（支持跨夜）；全局刷新间隔默认120秒，备选60/180/300秒。非采集时段不发自动请求。显式地点搜索单独计数，不自动请求。
- 单进程串行高德调用，单组每轮一次路径规划及最多一次静态地图；响应完成后0.5秒最小间隔。滚动32天 LBS 30,000次、地点搜索1,000次为本地硬保护，不是高德账户全局限额；失败请求也计数。额度持久化，阻断后不自动解除；恢复备份时关闭模块和授权并持久阻断，防止旧计数重新联网。实际账户及其他应用使用量需自行确认。三组每组每天4小时、2分钟一轮，32天理论23,040次 LBS，未含异常/其他使用。
- 路线按耗时排序、最多三条；不补造第三条。距离与拥堵长度来自供应商，缺失路况明确标为未知。完整原始坐标点生成三条灰度折线，不截断或臆造；长 URL、供应商限制、路况和静态图失败时允许只显示本轮数值而非旧地图。原图仅内存暂留，保留原供应商版权标记，无图片库。四分钟提示旧数据，十分钟清除，局域网30秒读取。预计耗时为采集时估算，不做倒计时。 
- 不改变既有自动分时的公交/家庭规则，驾驶以一级标签进入。只有同一页内三组地图，无独立测试或诊断界面。

## 验收范围

自动化使用虚构响应，不访问真实接口；真实账户、地图使用许可、接口是否返回三条、静态地图长 URL 上限、NAS 内存和 Kindle 可读性尚需现场确认。PR #22 已通过 rc.16 集成测试并合并主分支；rc.17 为现场验收候选，发布结果见项目状态及 Issue #19。
