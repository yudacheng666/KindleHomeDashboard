# 测试计划
初始化：公开路径和必要文档检查、Git 历史密钥扫描；上传前仍需独立脱敏审核，扫描不得打印真实秘密。公开 CI 使用标准免费 runner，任何真实数据或生产凭证均不得进入。检查当前工作流镜像版本和供应链风险，后续固定 digest。
核心模拟：解析、方向/站点匹配、ETA有效期、无车/停运/错误状态、调度与额度、独立降级、配置持久化、图像变化、更新恢复（适用时）。
真实接口：现有公交候选按已确认临时方案，在不绕过限制前提下验证实际线路/方向/ID及连续两辆 ETA，与官方消费端/实地对照；驾驶 API 核对实时路况和耗时；记录时间与结果于私有环境，公开仅脱敏摘要。
硬件：显示尺寸、中文、触摸、局刷残影、断网过期提示、重启、夜间策略、安全供电、阅读恢复。NAS测空闲和高频CPU/RAM及既有服务影响。初次交付覆盖代表性通勤和夜间周期；后续按变化选测。
当前已有公共示例真实接口探测，未完成实际通勤及硬件验收；CI是否通过以实际运行记录为准。
公交原型：Python 标准库、单站显式启用、默认30秒最低间隔/90秒有效期（候选参数，不代表授权额度）、无自动重试/后台线程；无实时数据不等于停运，空值保留旧数据须标记 stale，过期隐藏车辆。访问拒绝或限流停止请求，人工检查后才重新启用。测试使用完全虚构数据，覆盖解析、计划发车分离、重复车辆、无值/零值、HTTP 拒绝、缓存、退避。源时间、实际误差仍待实现或验证。
地图验收方案：用自有合法 Web 服务 Key 在私有环境，选无关公共起终点，调用高德路径规划2.0，要求返回各备选路线的 duration/distance/polyline/tmcs；同一算路结果中至少2条几何有区别的路线，按预计耗时比较，不制造路线。将同批路线以可区别样式送官方静态地图，验证真实图像、路线与底图对齐、版权标志、请求 URL/点数限制、灰度显示辨识度及额度；如服务只返回一条或地图拒绝，应如实提示。候选内部字段：route_id、duration_s、distance_m、geometry、traffic_segments、fetched_at、source（不把未提供路况标为畅通）；密钥仅本地，不记录完整URL。无凭证时不执行真实测试。


公交路线配置原型：按线路名搜索（单页最多20条），同线路 ID 的不同方向分别保留；方向详情以服务端真实站序为准，拒绝错误方向/线路及无效站点。按站序索引选择上下车站，保存前校验先后顺序；上车站用于 ETA。私有目录必须显式指定、位于代码目录及 Git 工作树之外，原子替换配置、Linux 权限0600；重启读取后需用新获取的线路详情复核站点 ID 和顺序。自动化测试用虚构线路、模拟 HTTP、临时目录；实际接口新代码、真实设备、管理鉴权、HTTP 接口及真机跨客户端同步尚待集成。首批公交与家庭分模块交付，驾车验收延后。

共享公交服务原型：单进程共享 BusService，显式启用；显示只读缓存，单一调度者调用 tick，选站保存后新建采集器并清旧 ETA，重启先查最新站序再采集。搜索缓存60秒、线路详情缓存10分钟（单条）。SQLite 私有文件持久化本地请求预算：每天 UTC 最多1000次（可降低）、所有请求间隔至少2秒、ETA至少30秒；失败计数，重启不重置间隔/额度/访问拒绝停用状态。以上仅本地保守候选参数，不是上游配额。模拟集成测试覆盖重复读、切站、重启验证、路线变更、限额、阻断及文件权限；现已增加回环 HTTP 服务、鉴权及分时后台循环；仍无真实 NAS/上游网络实测；不支持多进程共同运行，磁盘异常及系统时钟改变仍待系统级验证。当前读操作可能等待一次上游调用完成，后续网络服务需检查响应延迟。

本地 HTTP/调度集成原型：Python 3.10+ Linux，python -m dashboard --directory <private-dir>，启动前通过本机环境分别提供随机 KHD_READ_TOKEN 和 KHD_ADMIN_TOKEN；默认禁用公交，启用须明确 --enable-bus 和 --window（格式 DAYS:HH:MM-HH:MM，周一0至周日6，可跨午夜，默认时区 Asia/Shanghai）。单进程私有目录文件锁，HTTP 仅绑定127.0.0.1，Bearer 权限区分、拒绝跨源 Origin/异常 Host、禁止缓存、限制 JSON 大小、无请求日志；搜索/线路详情/保存选站使用一次性选择句柄。后台循环仅在指定时段采集，显示读取不触发上游请求；异常停止循环。测试用虚构数据、实际回环 HTTP 和模拟上游，验证权限、输入、预算、选站、暂停与循环退出。此入口仅供本地集成，不可直接暴露局域网或公网；正式局域网加密连接、配对/浏览器鉴权、防护及真机兼容待设计和验收。当前串行 HTTP/共享锁可能等待上游调用，响应延迟、慢请求和磁盘故障须进一步验证；家庭生活页面尚未开发。

公交浏览器联调页：固定回环入口 `/` 和 `/bus.js`，黑白大字号、ES5/XHR、无外部资源。令牌仅保存在当前页面内存、退出清除；只读与管理权限分开，服务端复核选站句柄与站序。显示轮询15秒只读本地缓存，异常时隐藏旧 ETA，状态区分陈旧/过期/暂停/限制访问；设置时暂停页面读取而不暂停后台调度。HTTP 同源/安全头/静态页无秘密测试及 Node 模拟 DOM/XHR 交互测试，不等于实际浏览器渲染或 Kindle 兼容性测试。尚无安全局域网入口，禁止直接对外暴露；令牌初次输入、配对、正式 TLS 与页面布局需真机确认。导航延后、家庭生活未编码。
