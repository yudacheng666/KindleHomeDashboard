# 测试计划
初始化：公开路径和必要文档检查、Git 历史密钥扫描；上传前仍需独立脱敏审核，扫描不得打印真实秘密。公开 CI 使用标准免费 runner，任何真实数据或生产凭证均不得进入。检查当前工作流镜像版本和供应链风险，后续固定 digest。

真实接口：合法授权后验证实际线路/方向/ID及连续两辆 ETA，与官方消费端/实地对照；驾驶 API 核对实时路况和耗时；记录时间与结果于私有环境，公开仅脱敏摘要。
硬件：显示尺寸、中文、触摸、局刷残影、断网过期提示、重启、夜间策略、安全供电、阅读恢复。NAS测空闲和高频CPU/RAM及既有服务影响。初次交付覆盖代表性通勤和夜间周期；后续按变化选测。
