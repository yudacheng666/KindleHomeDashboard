# 测试计划
初始化：公开路径和必要文档检查、Git 历史密钥扫描；上传前仍需独立脱敏审核，扫描不得打印真实秘密。公开 CI 使用标准免费 runner，任何真实数据或生产凭证均不得进入。检查当前工作流镜像版本和供应链风险，后续固定 digest。
核心模拟：解析、方向/站点匹配、ETA有效期、无车/停运/错误状态、调度与额度、独立降级、配置持久化、图像变化、更新恢复（适用时）。
真实接口：现有公交候选按已确认临时方案，在不绕过限制前提下验证实际线路/方向/ID及连续两辆 ETA，与官方消费端/实地对照；驾驶 API 核对实时路况和耗时；记录时间与结果于私有环境，公开仅脱敏摘要。
硬件：显示尺寸、中文、触摸、局刷残影、断网过期提示、重启、夜间策略、安全供电、阅读恢复。NAS测空闲和高频CPU/RAM及既有服务影响。初次交付覆盖代表性通勤和夜间周期；后续按变化选测。
当前已有公共示例真实接口探测，未完成实际通勤及硬件验收；CI是否通过以实际运行记录为准。
公交原型：Python 标准库、单站显式启用、默认30秒最低间隔/90秒有效期（候选参数，不代表授权额度）、无自动重试/后台线程；无实时数据不等于停运，空值保留旧数据须标记 stale，过期隐藏车辆。访问拒绝或限流停止请求，人工检查后才重新启用。测试使用完全虚构数据，覆盖解析、计划发车分离、重复车辆、无值/零值、HTTP 拒绝、缓存、退避。源时间、实际误差仍待实现或验证。
地图验收方案：用自有合法 Web 服务 Key 在私有环境，选无关公共起终点，调用高德路径规划2.0，要求返回各备选路线的 duration/distance/polyline/tmcs；同一算路结果中至少2条几何有区别的路线，按预计耗时比较，不制造路线。将同批路线以可区别样式送官方静态地图，验证真实图像、路线与底图对齐、版权标志、请求 URL/点数限制、灰度显示辨识度及额度；如服务只返回一条或地图拒绝，应如实提示。候选内部字段：route_id、duration_s、distance_m、geometry、traffic_segments、fetched_at、source（不把未提供路况标为畅通）；密钥仅本地，不记录完整URL。无凭证时不执行真实测试。


公交路线配置原型：按线路名搜索（单页最多20条），同线路 ID 的不同方向分别保留；方向详情以服务端真实站序为准，拒绝错误方向/线路及无效站点。按站序索引选择上下车站，保存前校验先后顺序；上车站用于 ETA。私有目录必须显式指定、位于代码目录及 Git 工作树之外，原子替换配置、Linux 权限0600；重启读取后需用新获取的线路详情复核站点 ID 和顺序。自动化测试用虚构线路、模拟 HTTP、临时目录；实际接口新代码、真实设备、管理鉴权、HTTP 接口及真机跨客户端同步尚待集成。首批公交与家庭分模块交付，驾车验收延后。

共享公交服务原型：单进程共享 BusService，显式启用；显示只读缓存，单一调度者调用 tick，选站保存后新建采集器并清旧 ETA，重启先查最新站序再采集。搜索缓存60秒、线路详情缓存10分钟（单条）。SQLite 私有文件持久化本地请求预算：每天 UTC 默认及最多3000次（可降低；原1000次计数继续保留）、所有请求间隔至少2秒、ETA至少30秒；失败计数，重启不重置间隔/额度/访问拒绝停用状态。以上仅本地保守候选参数，不是上游配额。模拟集成测试覆盖重复读、切站、重启验证、路线变更、限额、阻断及文件权限；现已增加回环 HTTP 服务、鉴权及分时后台循环；仍无真实 NAS/上游网络实测；不支持多进程共同运行，磁盘异常及系统时钟改变仍待系统级验证。当前读操作可能等待一次上游调用完成，后续网络服务需检查响应延迟。

本地 HTTP/调度集成原型：Python 3.10+ Linux，python -m dashboard --directory <private-dir>，启动前通过本机环境分别提供随机 KHD_READ_TOKEN 和 KHD_ADMIN_TOKEN；默认禁用公交，启用须明确 --enable-bus 和 --window（格式 DAYS:HH:MM-HH:MM，周一0至周日6，可跨午夜，默认时区 Asia/Shanghai）。单进程私有目录文件锁，HTTP 仅绑定127.0.0.1，Bearer 权限区分、拒绝跨源 Origin/异常 Host、禁止缓存、限制 JSON 大小、无请求日志；搜索/线路详情/保存选站使用一次性选择句柄。后台循环仅在指定时段采集，显示读取不触发上游请求；异常停止循环。测试用虚构数据、实际回环 HTTP 和模拟上游，验证权限、输入、预算、选站、暂停与循环退出。此入口仅供本地集成，不可直接暴露局域网或公网；正式局域网加密连接、配对/浏览器鉴权、防护及真机兼容待设计和验收。当前串行 HTTP/共享锁可能等待上游调用，响应延迟、慢请求和磁盘故障须进一步验证；家庭生活页面尚未开发。

公交浏览器联调页：固定回环入口 `/` 和 `/bus.js`，黑白大字号、ES5/XHR、无外部资源。令牌仅保存在当前页面内存、退出清除；只读与管理权限分开，服务端复核选站句柄与站序。显示轮询15秒只读本地缓存，异常时隐藏旧 ETA，状态区分陈旧/过期/暂停/限制访问；设置时暂停页面读取而不暂停后台调度。HTTP 同源/安全头/静态页无秘密测试及 Node 模拟 DOM/XHR 交互测试，不等于实际浏览器渲染或 Kindle 兼容性测试。尚无安全局域网入口，禁止直接对外暴露；令牌初次输入、配对、正式 TLS 与页面布局需真机确认。导航延后、家庭生活未编码。

家庭生活核心原型：独立私有 SQLite 文件（0600，沿用仓库外数据目录检查），本地日期驱动；单次任务逾期保留、每日/每周任务每次分别完成（周期不累计漏做项），已完成可撤销；关联海报实时读取任务标题，完成或非发生日隐藏，独立海报日期区间与启停；今日/周一至周日菜单及手动确认导入食材，精确文本去重按来源处理，菜单变更不删除已有购物条目/完成状态。已接入编辑/删除和回环 HTTP；历史管理/归档、轮播优先级与 NAS 实测待完成；不自动合并跨餐食材数量。测试用虚构内容与临时目录，不连接外部服务。

家庭管理接口：可独立使用 --enable-household 启用，沿用同一回环服务与只读/管理令牌。只读 view 仅展示当前有效内容，manage 可读取非活跃内容，所有写操作及管理查询需管理令牌；按固定操作白名单验证字段。编辑任务时若已有完成记录，拒绝日期/周期变更（可改标题）；删除任务须先解除关联海报，全部删除需显式 confirm=true，删除任务本身将清理其完成记录。菜单删改不删除购物条目，采购编辑保留完成状态。完成任务使用服务器本地日历日期，跨午夜旧页面请求拒绝。测试仅虚构内容和真实回环 HTTP，不外连。尚无历史归档/长期清理、手机/Kindle界面、真实局域网 TLS/配对与 NAS 实测；家庭与公交启动/故障隔离仍需完善，不能直接暴露此入口。

家庭网页联调原型：`/home`、`/home.js` 固定本机资源，ES5/XHR，不引用外部资源；今日总览、待办、海报、菜单、购物五个手动页面；管理令牌用于编辑、启停、完成撤销、删除确认、菜单日期查询、食材导入，查看令牌仅显示有效内容。刷新或换页时提示放弃未保存编辑；退出及 pagehide 清空令牌与显示；失败刷新隐藏旧数据，操作失败提示核对后重试。公交和家庭链接切换需重新连接，尚无统一登录/自动轮播或正式 Kindle 展示，暂用手动刷新；实际浏览器兼容、并发编辑、家庭数据备份及安全局域网接入待验收。模拟 DOM/XHR 与实际回环资源测试不等于真机验证。

家庭展示预览：/display 与 /display.js 为本机只读入口，今日概览、非空待办、每张有效海报、今日菜单、非空本周菜单及待购物项各自成页。默认手动，主动开始后按2/3/5分钟候选停留轮播（初值3分钟），周菜单和购物清单默认只手动查看、可加入轮播；手动翻页暂停轮播，设置仅当前会话生效。每30秒读取家庭本地数据，不调用公交或外部接口；内容相同避免重建画面，当前页消失回到总览，失败隐藏旧内容，401重新连接，隐藏标签暂停刷新与轮播，退出清空。测试用模拟DOM、定时器和XHR及实际回环静态资源；未验证真实浏览器渲染、长内容分页/自动字号、Kindle局刷、跨模块优先级、持久轮播设置及NAS安全接入。正式布局与默认规则待确认。

统一只读展示：/display 内公交/家庭手动切换共用同一内存令牌，不跨页面传递令牌；切换作废上一请求回调，清除旧内容，仅当前模块读取本地接口（公交15秒、家庭30秒），公交后台采集不受显示切换影响。家庭未启用或模块服务错误可手动切换，失效令牌退出；公交陈旧/过期状态明确，计划发车与 ETA 分离。家庭轮播设置仍为会话级，切公交停轮播计时，返回家庭从总览恢复先前启停设置；尚无自动跨模块分时优先级、统一管理登录或持久设置。新增模拟测试覆盖切换/读频率/过期和家庭禁用；真实 Chromium 集成脚本仅用虚构本地内容、关闭公交上游，验证手机新增任务、持久化、关联海报及菜单展示、一次连接切换和退出。真实 Kindle、长文本分页、局域网 TLS、NAS 部署待验收。

家庭显示完善：家庭数据库增加单行 display_settings，默认180秒、周菜单/采购不自动轮播、自动开始关闭；管理端明确保存，读端按内容变更同步（同一配置下手动暂停/临时调整不会被轮询覆盖），重新连接恢复已保存配置。迁移为原有 schema 的兼容新增表，不改变既有内容；只读令牌不可修改。长海报正文按54个Unicode码点/最多4个换行符分段，不截断，末页显示备注，字号按正文长度分级（38/30/24 CSS px）。仍需真机确认行宽、标题及备注高度、长待办/菜单分页，窄屏/过长内容允许滚动而非保证一屏。测试包含重开数据库、HTTP权限/无效设置、模拟定时及正文完整性、真实浏览器管理保存及展示恢复。跨模块自动分时规则仍待确认。

私有离线备份恢复：服务停止后运行 `python -m dashboard.backup backup --source <现有私有数据目录> --destination <尚不存在的备份目录>`；恢复使用 `python -m dashboard.backup restore --source <备份目录> --destination <尚不存在的新私有数据目录>`。目录父级须已存在且位于 Git 工作树外，备份不可嵌套在活动数据目录；同一进程锁拒绝运行中备份。仅白名单公交配置、请求预算、家庭 SQLite，数据库用 SQLite backup API 生成独立快照；逐文件 SHA-256、SQLite 完整性和外键、当前结构检查、0600 文件/0700 目录；不复制令牌、启动参数、日志、缓存及锁。恢复不覆盖旧目录，失败删除本次新建目录；旧备份可能早于供应商访问拒绝，因此恢复后强制阻断公交访问，不自动解除，需后续有审查的重新启用流程。只接受自己可信的备份；校验和防意外损坏而非防篡改认证，文件未加密，需 NAS 私有权限及另盘副本。单文件最大64MiB，旧结构不保证兼容。尚无图形管理入口、自动备份、真实 NAS 文件系统及掉电验收。测试仅虚构内容和临时目录。
