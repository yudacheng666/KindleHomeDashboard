# Docker 本机集成部署原型（未发布）

默认 compose.yaml 只供隔离测试：服务仍绑定容器内部 127.0.0.1:8080，不发布端口、不使用 host 网络，手机和 Kindle 暂不能直接连接。不要把端口转发到局域网或公网，也不要关闭安全校验。极空间 Docker/Compose 版本、CPU 架构、数据卷权限、家庭直连及真正的 NAS 资源占用仍待验收。

## 结构与运行

- 单容器，Python 3.12 slim Debian Bookworm，含时区及 CA 证书；无 pip 运行依赖、浏览器或外部数据库服务。
- 容器 UID/GID 10001；只读根文件系统、无额外 capabilities、禁止提升权限，初始上限 128MiB/0.5 CPU/32 PID。不是实测值。
- `compose.yaml` 需要 Compose v2 支持 bind.create_host_path；指定已经存在的私有目录与令牌环境文件。只默认启用家庭功能，公交联网默认关闭。
- 镜像构建仅包含 dashboard 运行源文件；真实数据、备份、凭证和部署参数放在仓库及构建上下文之外。
- `restart: unless-stopped` 在 Docker 服务正常启动且容器未被手动停止时可自动恢复。健康检查只确认本机静态 HTTP 页面响应，不证明数据源正常，不会自行重启不健康容器。
- SIGTERM/SIGINT 触发正常停止及后台采集退出；长时间异常上游或磁盘操作仍可能超过停止限时。

## 隔离测试操作（技术维护用，不要求普通用户现在执行）

在专用测试机上准备绝对路径的私有空目录，令 UID/GID 10001 具备读写权限，目录权限尽量为0700。不要对已有 NAS 共享目录递归改所有权。另准备仓库外0600环境文件，用本机密码学随机数分别生成独立的 KHD_READ_TOKEN / KHD_ADMIN_TOKEN（32字节随机数的 URL-safe 编码即可）；禁止公开、粘贴到聊天或 CI，不使用默认口令。Docker 管理员可读取容器环境，勿向他人共享 inspect/config 输出。

将 KHD_DATA_DIR、KHD_PRIVATE_ENV 指向上述绝对路径。执行 `docker compose config --quiet`、`docker compose build`、`docker compose up -d --no-build`。使用容器内部本机 HTTP 检查，不映射端口。健康检查、容器状态和停止操作可通过 Docker 管理器查看。停止使用 `docker compose stop`；不要删除数据目录。

## 升级与恢复

正式发布前需固定镜像版本及 digest，保留上一已验证镜像，备份数据库及独立的私有启动配置/令牌。停止服务后用 `dashboard.backup` 备份，检查返回结果；更新镜像时保留私有目录映射，若版本不兼容先在新目录恢复并验证。禁止自动回滚旧数据库结构或旧访问限制。恢复强制阻断公交联网，尚无受审查的重新启用入口。详见 TEST_PLAN.md。当前原型镜像标签 dev 不代表正式版本。

## 验收

`tests/docker_smoke.sh` 只用于隔离 Linux CI（需要 Docker Compose 和 sudo），生成虚构数据及临时令牌，不使用家庭网络。检查真实构建、非 root、资源限制、无端口映射、HTTP 鉴权、正常停止、删除并重建容器后的持久数据、镜像不含 Git/测试目录。采样资源不代表实际通勤负载或 NAS 兼容性。不得将真实数据导入测试。正式部署必须通过真实局域网、防火墙、设备及 NAS 独立验收。

## 家庭局域网直连（用户确认简化方向，未正式部署）

配对功能已移除。日常家庭使用不要求注册设备、输入只读令牌或维护证书。保留默认回环鉴权模式及可选 HTTPS；另提供独立 `compose.lan.yaml`（不要与默认 compose 合并）。私有配置指定 `KHD_LAN_HOST` 为 NAS 的固定私有 IPv4 地址，`KHD_LAN_NETWORK` 为可信家庭子网 CIDR，`KHD_DATA_DIR` 为仓库外数据目录。使用 `docker compose -f compose.lan.yaml config --quiet` 检查，待真实网络验收后才启动。手机/Kindle 浏览器访问该 NAS 地址的8080端口，/display 手动展示、/auto 自动分时展示、/home 家庭管理、/ 公交设置，无需配对或登录。默认开启家庭功能，公交联网仍须明确设置采集窗口。该模式显式 --open-admin，任何获准网段内可连接设备都可查看、修改及删除内容（仍有删除确认）。HTTP 不加密，不适用于不可信网络；禁止公网转发、访客网络访问、反向代理及其他会隐藏来源地址的中转。NAS 防火墙及路由器必须限制可信家庭网络，不能仅依赖 Docker 端口绑定；核查 Docker 转发规则及源地址保留，若 NAT 改写来源或实际网段不符合则不启用。服务器仅接受配置的 RFC1918 子网真实来源、精确 Host/Origin，不信任代理头。容器内监听 IPv4，宿主机发布仅指定私有地址。若需管理凭证，手动配置 --tls-cert/--tls-key 与 KHD_ADMIN_TOKEN，不使用 --open-admin；客户端必须验证证书；此可选配置尚无专门 Compose 模板。默认 LAN Compose 不使用凭证且停用旧回环健康检查，后续可补充适配的健康检查。通过默认 Compose 可回到原回环鉴权模式，不迁移业务数据库。普通用户无需现在执行命令，待 NAS/Kindle 可用后进行安装说明及现场验收。

## 自动分时显示（可选原型）

沿用私有启动参数中明确设置的公交采集窗口（NAS 配置时区、星期、开始/结束时间，支持跨午夜），不另设定时服务或真实通勤默认值。/auto 打开后自动选择：窗口内公交有配置且未禁用时显示公交，包括等待/过期/受限等真实状态；其余时间显示家庭，如家庭未启用则保留公交状态页。/display 默认手动，点击自动分时开启；手动选择模块（含同模块）、前后翻页、暂停轮播或进入轮播设置时退出分时，点击自动分时恢复。原家庭轮播启停及停留设置独立生效，不自动开启轮播。/auto 可作为设备收藏地址，重新打开自动恢复分时，手动覆盖不跨重启保存。按当前模块15/30秒读一次 NAS 本地自动展示接口，不调用公交上游，不改变采集频率；后台标签暂停，失败隐藏内容、恢复重读。未实现独立夜间休眠、置顶海报跨模块抢占或自动时段手机编辑；这些规则及正式布局待确认。Kindle 屏保/休眠下浏览器是否持续运行须实测。
