## 统一版式
- 竖屏白底、4px页边距；顶部日期时间与紧凑天气摘要各占50%，中线与下方双栏对齐，两栏文字分别左对齐，起始位置与下方对应栏一致（左侧时刻、下一行日期/星期，右侧天气温度/现象及体感湿度；首行同字体24px加粗（≤360px同为22px），次行同字体16px常规，行高及行距一致；不显示地点标题，保留轮播及带地点的预警）。总览唯一设置入口移至右下角，使用本地矢量齿轮图标及44px点击区，固定在可视屏幕右下角，不随内容滚动；正文独立滚动至按钮上方，避免遮挡；独立页面原设置入口不变。公交全宽、首车/次车左右并排；槽位标签移至预计到站或计划发车时间前（以中点分隔），不再独占一行，失效时保留槽位标签但不显示过期预计时间。公交在总览仅显示线路、乘车方向、首车/次车状态、计划/预计时刻及有意义的剩余站数/距离；不重复显示“最近一辆/下一辆”“发车计划”“本站到站时间未知”等说明。总览不显示常规采集更新时间；公交区域总高度固定（149px，≤420px为170px，≤360px为210px，与rc.37预算一致），标题、方向、异常状态及双车有内容的行自上紧凑排列，空行隐藏，剩余空间集中到底部，不改变下方模块位置；窄屏为长文字预留更高上限，超长文字可在行内滚动，线路标题可通过详情查看全名。保留真实ETA、预计/计划时刻、旧数据/过期/时钟异常等提示及90秒本地失效检查；独立公交页的完整信息不变。
- 前两个目的地改为左右并排卡片，每张地图保持原图比例和完整范围，地图展示框高140px；目的地名称自然换行、不预留第二行高度，路线摘要放在地图下方，每条路线一行，编号/耗时/距离分列对齐，最快路线加粗。总览不显示常规采集更新时间，不预留空行；保留返程、旧数据、路线不足、地图异常等必要状态及地图内换向按钮，耗时60分钟起用小时和分钟；超过两个目的地时只显示“另 N 个目的地”入口；不足三个时无额外链接，完整驾驶页仍由设置进入。窄屏手机（≤420px）改为上下卡片，避免地图和路线字挤得不可读；600px Kindle 竖屏保持左右两张地图。
- 下方菜单和待办分别分组，菜单按日期、餐次组织，今日无排餐不显示今日空分组；待办按日期组织；公交、驾驶、菜单与待办相邻分组仅保留一条分隔线；去除更新时间对应空行、重复边框及多余间距，保留左右分隔和日期分组，不增加重复大标题。保留既有展示范围、最多三条待办和完成按钮。海报独立显示。
