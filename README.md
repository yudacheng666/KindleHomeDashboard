# KindleHomeDashboard
个人自用的 Kindle 家庭信息终端，目标为真实通勤信息、天气、待办、菜单和低维护运行。
当前为现场验收候选阶段。按模块逐步上线，一级入口为公交、待办清单、海报、本周菜单，驾车地图后续加入，天气可独立追加。入口：[开发规则](AGENTS.md)、[安全](SECURITY.md)、[需求](docs/REQUIREMENTS.md)、[调研](docs/RESEARCH.md)、[设计建议](docs/ARCHITECTURE.md)、[项目状态](docs/ai-memory/PROJECT_STATE.md)。
